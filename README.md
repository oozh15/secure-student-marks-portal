Secure Student Mark Management System  Blockchain
Tech Stack: Solidity, Ethereum, Firebase Auth, Cryptography, Web Stack.

Description:
Architected an immutable system using Ethereum and client-side encryption derived from Firebase authentication to secure academic records.Developed real-time analytics for automated grade and rank calculation, featuring Bulk CSV Upload for efficient batch data processing.

Use Case: Provides a decentralized, tamper-proof platform for schools to manage sensitive student data without central authority risks.
